## 🔧 Troubleshooting

### If Build Fails:
- Check Vercel build logs
- Verify `web` is set as root directory
- Ensure all dependencies are in package.json

### If Arabic Text Doesn't Display:
- Verify tools.json was deployed (check file size: 20KB)
- Check Cairo font loads from Google Fonts
- Inspect browser console for errors

### If 404 Errors:
- Confirm root directory is `web`
- Check that `.next` folder generates during build
